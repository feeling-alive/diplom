# FinTrack Backend — краткая карта для агента

## Стек
- **Python 3.11+**, **FastAPI**, **Uvicorn**
- **PostgreSQL 14** + SQLAlchemy 2.0 async (asyncpg) + Alembic
- **Redis** (кэш котировок, graceful degradation)
- **APScheduler** (новостной фетчер каждые 4 ч)
- **JWT** (HttpOnly cookie, bcrypt, python-jose)
- **Google OAuth** (кнопка на фронте)
- **Docker Compose** (postgres:5432 + redis + backend)

## Структура `backend/app/`

```
app/
├── main.py            # FastAPI app, lifespan (create_all, APScheduler), CORS, /uploads, /health
├── config.py          # Pydantic Settings из .env (все TTL, ключи, URL)
├── database.py        # async engine, AsyncSession, get_db dependency
├── models.py          # 9 ORM-моделей (см. ниже)
├── utils.py           # safe_float — защита от NaN/None
├── auth/
│   ├── router.py      # POST register/login/logout, GET me, Google OAuth (/auth/*)
│   ├── dependencies.py# get_current_user (JWT cookie), get_optional_user, require_admin
│   ├── utils.py       # hash_password/verify_password (bcrypt), create/decode JWT
│   └── schemas.py     # RegisterRequest, LoginRequest, UserResponse, TokenResponse
├── routes/
│   ├── quotes.py      # /api/quotes/stock/{s}, /stocks, /ohlcv/{s}, /coin/{id}, /fng, /funding-rate, /gas
│   ├── crypto.py      # /api/quotes/crypto/{symbol} (OKX)
│   ├── forex.py       # /api/quotes/forex/{base}/{quote} (Frankfurter)
│   ├── dashboard.py   # GET/PUT /dashboard/config (multi-dashboard envelope)
│   ├── profile.py     # GET/PATCH /users/me, check-username, avatar upload
│   ├── subscription.py# GET /subscription/status, POST upgrade/cancel
│   └── news.py        # /api/news — feed, favorites, comments, reactions likes
└── services/
    ├── cache.py       # Redis get/set/close_client, все операции try/catch — если Redis нет, всё работает
    ├── finnhub.py     # stock quote, кэш stock_ttl (60s)
    ├── okx.py         # crypto ticker, кэш crypto_ttl (30s)
    ├── frankfurter.py # forex rate, кэш forex_ttl (300s)
    ├── candles.py     # OHLCV: OKX (crypto) + Finnhub (stocks), fallback .json
    ├── coingecko.py   # coin info, кэш 30min, fallback mock
    ├── fng.py         # Fear & Greed, кэш 1h, fallback 50/Neutral
    ├── funding.py     # OKX funding rate, кэш 30s
    ├── gas.py         # Etherscan gas oracle, кэш 15s, fallback stale
    └── news_fetcher.py# APScheduler: 4 bucket'a NewsAPI -> OpenRouter AI (перевод, категория, символы)
```

## Модели БД (9 таблиц)
| Модель | Назначение |
|--------|-----------|
| `User` | email, username, password_hash, google_id, role (user/admin), avatar_url, is_active |
| `Subscription` | plan (free/premium), expires_at, ai_requests_used. 1:1 с User |
| `DashboardConfig` | layout (JSON — multi-dashboard envelope). 1:1 с User |
| `ChatSession` | AI-чат сессия, symbol + messages (JSON). 1:N к User |
| `Comment` | комментарий к новости (article_url). 1:N к User |
| `Favorite` | избранный символ (user_id + symbol unique). 1:N к User |
| `NewsArticle` | кэш новости: title, description, content, url, source, category, symbols, keywords, market_impact, ai_processed, переводы `_ru` |
| `NewsReaction` | лайк/дизлайк (user_id + article_id unique) |
| `NewsFavorite` | избранная новость (user_id + article_id unique) |

## Redis (кэширование)
- **Graceful degradation**: если Redis недоступен, get_cached возвращает None, set_cached молча дропает.
- Ключи: `cache:stock:{sym}`, `cache:crypto:{sym}`, `cache:forex:{base}:{quote}`, `cache:ohlcv:{sym}:{tf}:{limit}`, `cache:coin:{id}`, `cache:fng`, `cache:funding:{sym}`, `cache:gas`, `news:list:{md5}`.
- TTL для каждого источника в `config.py` (stock 60s, crypto 30s, forex 300s, ...).

## Философия graceful degradation
Любая внешняя зависимость (БД, Redis, API-ключи) может отсутствовать — сервис не падает:
- Нет PostgreSQL → create_all пропущен, роуты с БД возвращают 500
- Нет Redis → кэш прозрачно отключён
- Нет Finnhub/Api ключа → возвращаются нулевые/статические заглушки
- CoinGecko/NewsAPI недоступен → mock fallback

## Запуск
```bash
cd backend
pip install -r requirements.txt
# Нужен .env с DATABASE_URL, REDIS_URL, FINNHUB_API_KEY и т.д.
uvicorn app.main:app --reload --port 8000
# Или через Docker Compose из корня проекта
```
