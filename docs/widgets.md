## Режим редактирования

Кнопка «Редактировать» включает режим:
- Перетаскивание виджетов (drag & swap)
- Изменение размера (resize за край)
- Удаление виджетов (крестик)
- Пунктирная рамка вокруг виджетов

## Drag-and-Drop

- Виджеты перетаскиваются только в режиме редактирования
- При перетаскивании на место другого виджета — они меняются местами (swap)
- `compactType="vertical"` + `preventCollision={true}` обеспечивают корректное поведение
- Pre-drag позиции сохраняются при начале драга для корректного swap

## Изменение размера

- Потяните за край виджета для изменения размера
- Размер привязывается к ближайшему из `availableSizes`
- Овальный индикатор `W × H` показывается над виджетом во время resize
- Анимация через CSS transitions на `.react-grid-item`

## Карусель страниц

- Если виджеты не помещаются на одну страницу — появляется навигация
- Стрелки влево/вправо для переключения
- Индикаторы страниц (точки)
- Анимация слайда через Framer Motion

## Добавление виджетов

Модальное окно «Добавить виджет»:
- Поиск по названию и описанию
- Выбор размера перед добавлением
- Перетаскивание из модального окна в сетку
- Автоматическое размещение в свободном слоте
