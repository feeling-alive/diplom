# FinTrack Dashboard

> Финансовый дашборд с интерактивными виджетами, DnD и каруселью страниц.

## Быстрый старт

```bash
npm install
npm run dev
```

## Возможности

- **Система виджетов** — 11 типов: графики, таблицы, индикаторы, новости
- **Drag-and-Drop** — перетаскивание и свап виджетов в режиме редактирования
- **Resize** — изменение размера виджетов перетаскиванием за край
- **Карусель страниц** — навигация стрелками при большом количестве виджетов
- **localStorage** — сохранение расположения виджетов
