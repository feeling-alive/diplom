В проекте FinTrack нужно реализовать две задачи.

ЗАДАЧА 1 — Восстановление пароля через email.

Нужен полный flow из трёх шагов:

1. Страница /forgot-password: форма с полем email. При отправке бэкенд 
генерирует токен, сохраняет его в Redis с TTL 15 минут и отправляет 
письмо пользователю со ссылкой на сброс пароля. Если email не найден — 
не раскрывать это, просто показать нейтральное сообщение «если аккаунт 
существует, письмо отправлено».

2. Страница /reset-password?token=...: читает токен из URL, проверяет 
валидность через бэкенд. Если токен истёк или не существует — показать 
ошибку с кнопкой вернуться на /forgot-password. Если валиден — форма 
с двумя полями «новый пароль» и «повторите пароль».

3. При успешной смене: токен удаляется из Redis, хэш пароля обновляется 
в таблице users. Редирект на страницу логина с сообщением об успехе.

Для отправки писем использовать fastapi-mail. SMTP-настройки брать из 
переменных окружения: SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD, 
SMTP_FROM. Добавить эти переменные в .env.example с комментариями.

Ссылка в письме формируется из переменной окружения FRONTEND_URL.
Стиль письма — минимальный HTML, в цветовой схеме проекта (акцент #E11D48).

ЗАДАЧА 2 — Убрать индексы (биржевые индексы типа S&P 500, NASDAQ и т.д.) 
из всего проекта.

Для этого типа активов нет подключённого API, поэтому нужно:
— убрать индексы из всех выпадающих списков, табов и фильтров где они 
  фигурируют как категория активов
— убрать из таблицы обзора рынка если там есть отдельная вкладка/фильтр 
  по индексам
— убрать из виджетов дашборда если какой-то виджет заточен только под индексы
— убрать из навигации и любых упоминаний в UI

Оставить только: крипта, акции, форекс.
