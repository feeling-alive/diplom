# Resize ушёл за maxH + сломанные превью виджетов в модале

**Date:** 2026-05-17 02:49
**Files:** src/pages/Dashboard.tsx, src/components/dashboard/WidgetPreview.tsx, src/components/dashboard/AddWidgetModal.tsx
**Severity:** high

## Problem

После перевода виджетов на flex-layout с `<ResponsiveContainer width="100%" height="100%">`:

1. На дашборде виджет «График цены» вытянулся в узкий вертикальный прямоугольник высотой ~640px (gridW≈1, gridH≈4) — далеко за `maxH:3` в registry. Контент карточки расползался по высоте.
2. Превью виджетов в модале `AddWidgetModal` были пустыми/обрезанными — графики (`AreaChart`, `PieChart`) не рендерились.

## Root Cause

Три независимых, но рядом всплывших ошибки.

**1. RGL не знал лимитов resize.**
`buildGridLayout()` передавал в `<GridLayout>` только `{i, x, y, w, h}` без `minW/maxW/minH/maxH`. RGL по умолчанию даёт безлимитный resize. Клемп на `def.minW/maxW/minH/maxH` был только в `handleResizeStop` — то есть пользователь физически тянул виджет за пределы, и только когда отпускал — размер «прыгал» обратно. На fast-moving drag промежуточные размеры успевали записаться в state, и при `compactType="vertical"` соседи сдвигались под уже-некорректные координаты.

**2. localStorage хранил «залётевшие» размеры.**
`loadWidgets()` доверял JSON в localStorage без проверки. Любое старое значение `{w:1, h:4}` для виджета с `maxH:3` рендерилось как есть после перезагрузки.

**3. ResponsiveContainer коллапсирует в parent с `height: auto`.**
`WidgetPreview` обёртывал виджет в `<div style={{ height: '100%' }}>`, но родитель в модале не задавал высоту явно. ResponsiveContainer (по докам Recharts) для расчёта своего height читает реальные пиксели родителя через ResizeObserver — если родитель имеет `height: auto` и его собственная высота определяется содержимым, получается замкнутый цикл, ResponsiveContainer падает в 0px. Графики/pie исчезали.

## Solution

**1.** В `buildGridLayout(widgets)` найти `WIDGET_REGISTRY.find(r => r.type === w.type)` и добавить `minW/maxW/minH/maxH` к каждому GridItem. Тип `GridItem` расширен опциональными полями. Теперь RGL нативно блокирует resize-handle на границе, ещё до того как пользователь её перетащит.

**2.** В `loadWidgets()` после `JSON.parse` пройти `.map()` и заклемпить `w/h` каждого виджета по текущему registry. Добавлен debug-лог `[FIX] clamp loaded widget %s %dx%d -> %dx%d` — видно в DevTools, когда фикс сработал. Это самоисцеляет старые сессии.

**3.** В `WidgetPreview` ввести карту `PREVIEW_HEIGHTS` со статическими высотами на каждый тип виджета (110-220px в зависимости от плотности контента). Само превью получило `position: relative` и `overflow: hidden`. ResponsiveContainer теперь видит конкретный px-родитель и нормально рендерит SVG. Дополнительно `AddWidgetModal` стал передавать в `WidgetPreview` выбранный `selected.w/selected.h`, чтобы превью рендерилось в правильном адаптивном режиме (например, KPI 4×1 — compact-режим, а не вертикальный список).

## Prevention

- В react-grid-layout **всегда** прокидывать `minW/maxW/minH/maxH` в сами layout items. `onResize*` callbacks — только последняя линия обороны для случаев, когда лимиты меняются на лету; основные границы должна знать сама RGL для блокировки на drag-handle.
- Любой код, который читает из localStorage и возвращает компонентам в state, должен иметь validate/clamp слой. Persisted state переживает refactor’ы registry/схем и тащит за собой старые баги.
- Recharts `<ResponsiveContainer>` **никогда** не работает с parent у которого `height: auto`/`height: fit-content`/нет явной высоты. Внутри flex-column родитель должен быть либо `flex: 1; min-height: 0`, либо иметь фиксированный `height: Npx`. Для статических превью (модалы, гайды, документация) — выбирать фиксированный px-height; для растягиваемых ячеек дашборда — flex с явным `min-height: 0`.
- Для виджетов с адаптивным поведением по `gridW/gridH`: передавать реальный целевой размер в превью, а не дефолтные 2×2 — иначе превью обманывает пользователя относительно того, что он получит при выбранном размере.
