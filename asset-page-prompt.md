# FinTrack — Asset Page: Полная реализация

## Контекст проекта

React 18 + TypeScript + Framer Motion + Recharts. Маршрут `/asset/:symbol`. Уже существует базовая заглушка страницы. Данные о ценах приходят из хуков `useAssetPrice` и `useOHLCV` (OKX для крипто, Finnhub для акций). Визуальный стиль: фон `#F4F3F1`, белые карточки, акцент `#E11D48`, скругления 16px, шрифт Inter. Приложение использует общий AppLayout с иконочным сайдбаром слева.

---

## Макет страницы

Страница делится на две колонки. Левая колонка занимает 65% ширины и содержит шапку актива, главную карточку с графиком и метрики. Правая колонка занимает 35% и содержит ленту новостей и заглушку ИИ-панели. Обе колонки выровнены по верхнему краю, между ними отступ 16px.

---

## Шапка актива

Полная ширина страницы над колонками. Содержит: иконку актива (цветной круг с инициалом), полное название, тикер серым, текущую цену крупным шрифтом, изменение за 24 часа в цветной таблетке (зелёная при росте, красная при падении), кнопку со звёздочкой "Добавить в список". Данные берутся из `useAssetPrice(symbol)`.

---

## Главная карточка — три режима

Белая карточка, занимающая всю левую колонку ниже шапки. Внутри карточки в верхнем левом углу три кнопки-таба, визуально "исходящие" из карточки: они слегка выступают из верхней грани карточки как язычки. Активный таб сливается с карточкой цветом. Переключение между табами меняет содержимое внутри карточки с анимацией появления через Framer Motion.

### Таб 1 — "Обычный"

Recharts AreaChart по данным из `useOHLCV(symbol, selectedTimeframe)`. Над графиком справа — pill-группа таймфреймов: 1Ч / 4Ч / 1Д / 1Н / 1М. Активный таймфрейм — тёмный фон. Линия графика и градиентная заливка используют акцентный цвет при росте и красный при падении. Ось Y — справа, ось X — снизу, серые пунктирные горизонтальные гайдлайны. При наведении на график — вертикальная линия и тултип с ценой и временем. Скелетон при загрузке.

### Таб 2 — "Про график ↗"

Клик по этому табу не меняет содержимое карточки, а открывает fullscreen-модальное окно. Иконка стрелки-выхода рядом с текстом таба визуально сигнализирует об этом поведении.

### Таб 3 — "Информация о монете"

Вместо графика появляется информационный блок. Данные запрашиваются из CoinGecko API: `https://api.coingecko.com/api/v3/coins/{coinId}` — без API-ключа, бесплатно. Маппинг символа к CoinGecko ID хранится в отдельном файле-константе (BTC→bitcoin, ETH→ethereum и т.д.). Блок содержит: описание проекта (первые 400 символов с кнопкой "Читать далее"), ключевые ссылки (официальный сайт, GitHub, Twitter — иконки + текст), дату запуска, алгоритм/тип актива, рейтинг на CoinGecko, статистику: ATH (исторический максимум с датой), ATL (исторический минимум с датой), общее предложение, находящееся в обращении предложение. При отсутствии данных (акции, форекс) — сообщение "Расширенная информация доступна только для криптоактивов".

## Метрики под карточкой

Горизонтальная полоска из метрик под главной карточкой. Метрики: Капитализация, Объём 24ч, Максимум 24ч, Минимум 24ч, Спред, Количество сделок. Данные из OKX и CoinGecko. Если метрик больше чем помещается в ширину — горизонтальный скролл колесиком мыши и стрелками влево/вправо по краям полоски. Стрелки появляются только когда есть что скроллить. Каждая метрика: мелкий серый лейбл сверху, значение жирным снизу.

---

## Модальное окно "Про график"

Открывается поверх всего приложения при клике на таб "Про график ↗". Apple-стиль: фон за модальным окном — тёмное размытое стекло (`backdrop-filter: blur(20px)`, `background: rgba(0,0,0,0.6)`). Появление через Framer Motion: scale 0.95 → 1, opacity 0 → 1, spring transition. Размер окна: 92vw × 90vh, скругление 20px, белый фон.

Внутри окна две зоны. Левая (70% ширины) — TradingView Advanced Chart Widget, встроенный через iframe. Symbol для виджета формируется из тикера актива (BTC → BINANCE:BTCUSDT, AAPL → NASDAQ:AAPL). Виджет использует тему "light", язык "ru", все инструменты включены, hide_top_toolbar: false, allow_symbol_change: false. Правая зона (30%) — заглушка ИИ-панели: иконка робота, заголовок "ИИ-ассистент", подзаголовок серым "Подключение к аналитической модели — следующий этап", три неактивные серые кнопки-подсказки с примерами запросов ("Проанализируй текущий тренд", "Найди уровни поддержки", "Оцени риски входа"). Кнопка закрытия модального окна — крестик в правом верхнем углу.

## Правая колонка

### Новости по активу

Карточка занимает верхние 60% правой колонки. Заголовок "Новости" + название актива. Данные из `useNews(symbol)`. Список новостей с вертикальным скроллом внутри карточки (не страницы). Каждая новость: цветная точка настроения, заголовок, источник и время публикации серым. Клик — открывает URL в новой вкладке. Скелетон при загрузке.

### Заглушка ИИ-панели

Карточка занимает нижние 40% правой колонки. Серый фон внутри карточки. Иконка робота 48px, заголовок "ИИ-ассистент", подзаголовок "Будет доступен после подключения аналитической модели". Три кнопки-подсказки с примерами запросов — неактивные, серые, скруглённые. Поле ввода внизу — неактивное, серый placeholder "Задайте вопрос об активе...". Всё это визуально отличается от активных элементов: пониженная непрозрачность 0.6, cursor: not-allowed.

## Данные и источники

Цены в реальном времени — `useAssetPrice(symbol)` (уже реализован). OHLCV для простого графика — `useOHLCV(symbol, timeframe)` (уже реализован). Метаданные монеты — новый хук `useCoinInfo(symbol)`, запрашивает CoinGecko без авторизации, кэш React Query 30 минут. Новости — `useNews(symbol)` (уже реализован). TradingView виджет — iframe, данные предоставляет TradingView, никаких запросов с нашей стороны.

---

## Анимации и переходы

Переключение табов внутри карточки — Framer Motion AnimatePresence, содержимое уходит влево/приходит справа. Открытие модального окна — scale + opacity spring. Закрытие — обратная анимация. Появление метрик — stagger 0.05s. Новости — stagger при первой загрузке. Hover на строках — translateY(-1px), усиленная тень.

---

## Ограничения

Не устанавливать новые npm-пакеты кроме необходимых для TradingView виджета если потребуется. TradingView виджет встраивать через iframe с официальным URL виджета — не через npm-пакет. Не изменять существующие хуки — только добавить `useCoinInfo`. Не трогать AppLayout, роутинг и другие страницы. После реализации убедиться что `npx tsc --noEmit` проходит без ошибок.

---

## Критерии готовности

Страница открывается по `/asset/BTC-USDT` и `/asset/AAPL` без ошибок. Три таба работают, переключение анимировано. Клик на "Про график" открывает модал с TradingView. Модал закрывается на крестик и по клику на фон. В табе "Информация о монете" отображаются реальные данные с CoinGecko для крипто и сообщение-заглушка для акций. Метрики скроллятся колесиком. Новости загружаются. ИИ-панель отображается как неактивная заглушка.
