# Размеры виджетов FinTrack (Dashboard)

Документ описывает размеры всех виджетов дашборда в пикселях и долю, которую
занимают внутренние элементы внутри каждого виджета.

Источники: `src/pages/Dashboard.tsx`, `src/constants/widgets.registry.ts`,
`src/components/dashboard/WidgetCard.tsx`, `src/index.css`,
`src/components/dashboard/**`.

---

## 1. Система сетки (react-grid-layout)

Параметры из `Dashboard.tsx`:

| Параметр            | Значение | Где задано           |
| ------------------- | -------- | -------------------- |
| Колонок (`COLS`)    | **4**    | `const COLS = 4`     |
| Высота строки       | **110px**| `ROW_HEIGHT = 110`   |
| Отступ между ячейками (margin) | **10px** | `GRID_MARGIN = 10` (по X и Y) |
| Padding контейнера  | **0px**  | `containerPadding={[0,0]}` |

Виджет задаётся в «грид-единицах» `w × h` (ширина в колонках × высота в строках).
Например `2×2`, `3×1`, `1×4`.

### Формулы перевода грид-единиц в пиксели

```
ширина колонки  colW = (W_контейнера − margin·(COLS−1)) / COLS = (W − 30) / 4
ширина виджета  = colW · w + (w − 1) · 10
высота виджета  = 110 · h + (h − 1) · 10
```

**Высота фиксирована** (не зависит от ширины окна):

| h (строк) | Высота, px |
| --------- | ---------- |
| 1         | **110**    |
| 2         | **230**    |
| 3         | **350**    |
| 4         | **470**    |

### Ширина грид-контейнера

Контейнер сетки = ширина окна − «хром» приложения:

```
W_контейнера = viewport − 24 (padding .app-page) − 56 (.app-rail) − 44 (padding .main-scroll)
             = viewport − 124
```

### Ширина виджета по w для типовых разрешений экрана

| viewport | W_контейнера | colW   | w=1    | w=2   | w=3     | w=4   |
| -------- | ------------ | ------ | ------ | ----- | ------- | ----- |
| 1920px   | 1796         | 441.5  | 441    | 893   | 1344    | 1796  |
| 1536px   | 1412         | 345.5  | 345    | 701   | 1056    | 1412  |
| 1440px   | 1316         | 321.5  | 321    | 653   | 984     | 1316  |
| 1280px   | 1156         | 281.5  | 281    | 573   | 864     | 1156  |

> Высоты всегда: h1=110, h2=230, h3=350, h4=470 px независимо от разрешения.

## 2. Оболочка виджета (WidgetCard) — общая для всех

`WidgetCard.tsx`, `box-sizing: border-box`. Размеры внутри карточки:

| Элемент карточки         | Размер            |
| ------------------------ | ----------------- |
| Граница (border)         | 1px со всех сторон |
| Padding                  | 10px со всех сторон |
| Радиус скругления        | 12px              |
| Шапка (drag-handle)      | высота ≈ 18px + `marginBottom: 6px` |
| ├─ иконка-плашка         | 18×18px, радиус 5px, иконка 11px |
| ├─ gap иконка↔заголовок  | 5px               |
| └─ заголовок             | font 10px, weight 600 |
| Кнопка удаления (×)      | абсолютная, иконка 12px, верхний правый угол |
| Контент                  | `flex: 1` (вся оставшаяся высота) |

### Сколько места внутри занимают зоны (по высоте карточки H)

```
рабочая высота  = H − 2 (border) − 20 (padding)         = H − 22
зона шапки      = 18 (иконка) + 6 (marginBottom)        = 24
зона контента   = (H − 22) − 24                          = H − 46
рабочая ширина  = W − 22  (контент по ширине)
```

| h | Высота H | Шапка | Контент (px) | Доля контента | Доля «хрома»+шапки |
| - | -------- | ----- | ------------ | ------------- | ------------------ |
| 1 | 110      | 24px  | **64px**     | ~58%          | ~42%               |
| 2 | 230      | 24px  | **184px**    | ~80%          | ~20%               |
| 3 | 350      | 24px  | **304px**    | ~87%          | ~13%               |
| 4 | 470      | 24px  | **424px**    | ~90%          | ~10%               |

> Чем выше виджет, тем больше доля контента (шапка и паддинги фиксированы).

## 3. Виджеты: размеры и внутренние элементы

Для каждого виджета: доступные размеры (грид-единицы → px высота фикс.,
ширина зависит от экрана), и разбивка внутренних элементов.
«Контент» = внутренняя зона после шапки (см. §2).

---

### 3.1 Тикер активов · `market_ticker`
- **Размеры:** 2×1, 3×1, 2×2, 3×2 · по умолчанию **3×1** · min 2×1, max 3×2
- **Высоты:** h1=110px, h2=230px
- **Внутри:** CSS-grid `repeat(cols, 1fr)` строк `1fr`, gap **6px**.
  Кол-во ячеек = строки × колонки. Каждая ячейка `AssetCell`:
  - padding **8px**, радиус 8px, фон `--bg`
  - иконка-кружок **24×24px** (font 11)
  - gap между элементами **8px**
  - символ (font 11/600), цена (font 11/700, прижата вправо), бейдж % (font 10, padding 2×6, радиус 999)
- **Доли:** все ячейки равны (1fr), занимают 100% контента минус gap 6px.
